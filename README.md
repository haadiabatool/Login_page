# Front-End login Page <br>
This project is built using HTML&CSS.<br>

## 🔰 Features <br>
🔷Modern,Clean login form<br>
🔷Email and Password input fields <br>
🔷"Remember Me" checkbox <br>
🔷"Forget password" and "Sign Up" Links <br>
🔷Smooth focus effects and hover transitions <br>
🔷Box shadows and gradient backgrounds for modern look <br>

## 🔰 Technologies Used <br>

🔷**HTML5** Structure of the login page <br>
🔷**CSS3** Styling, gradient,shadows, and responsive layout <br>
🔷**Flexbox** Centering and alignment of the form  <br>
🔷**JavaScript** Form Toggle functionality
