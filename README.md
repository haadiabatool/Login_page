#Front-End login Page
This project is built using HTML&CSS.

## Features
-Modern,Clean login form
Email and Password input fields
"Remember Me" checkbox
"Forget password" and "Sign Up" Links
Smooth focus effects and hover transitions
Box shadows and gradient backgrounds for modern look

## Technologies Used 

**HTML5** Structure of the login page
**CSS3** Styling, gradient,shadows, and responsive layout
**Flexbox** Centering and alignment of the form
